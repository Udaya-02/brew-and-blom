# Brew & Bloom Coffee Co.

Brew & Bloom Coffee Co. is a modern, responsive coffee shop website designed to provide a premium and engaging café experience through a clean and user-friendly interface.

## Features

- Responsive coffee shop website
- Modern and user-friendly UI
- Hero section and café branding
- Menu and featured coffee products
- About/Our Story section
- Responsive layout for different screen sizes
- Clean component-based frontend structure

## Technologies Used

- React
- TypeScript
- Vite
- CSS
- Google AI Studio for AI-assisted development

## Project Highlights

- Developed a responsive frontend interface for a coffee shop.
- Built reusable UI components using React and TypeScript.
- Designed the website with a focus on usability, visual consistency, and responsive design.
- Used AI-assisted development to support the project development workflow.
